# Contributing to SinkSharp

Thank you for your interest in SinkSharp!

## Reporting issues

- Use [GitHub Issues](https://github.com/SinkSharp/Samples/issues) on the public Samples repo
- For security issues, email [support@sinksharp.com](mailto:support@sinksharp.com) privately — do not open a public issue

## Requesting features

Open a [GitHub Discussion](https://github.com/SinkSharp/Samples/discussions) describing the use case.

## Questions

Email [support@sinksharp.com](mailto:support@sinksharp.com) or open a Discussion.
